# Project FU affinity icon attribution

The module loads the nine affinity PNG icons directly from the installed Project FU system at `systems/projectfu/styles/static/affinities/icons/`. No icon artwork is distributed in this repository or release ZIP. The module's MIT license covers its software, not those external assets.

Project FU's [art reference master list](https://github.com/League-of-Fabulous-Developers/FoundryVTT-Fabula-Ultima/blob/7eb305911ebdd69c90cdde6574b11a0cd2ab3461/styles/static/art-reference-master-list.txt) credits **t3nshi (explicit permission)** for `affinities/icons/*`, with a separate exception crediting **Mildew (explicit permission)** for `water.png`.

- t3nshi: [Bluesky](https://bsky.app/profile/t3nshi.bsky.social), [Instagram](https://www.instagram.com/_t3nshi)
- Mildew: [Ko-fi](https://ko-fi.com/not_mildew), [Linktree](https://linktr.ee/not_mildew)
- Project FU's [copyright and contributor credits](https://github.com/League-of-Fabulous-Developers/FoundryVTT-Fabula-Ultima/blob/7eb305911ebdd69c90cdde6574b11a0cd2ab3461/COPYRIGHT.md)

The original supplied PNGs match the Project FU v4.16.3 and referenced upstream icons byte for byte. This module uses physical, air, bolt, dark, earth, fire, ice, light, and poison; it does not use water or introduce extra damage types. Upstream lists the separate parent-folder affinity symbols as generated with IcoMoon from the Fabula Ultima license kit; that entry is distinct from the PNG icons used here. Upstream's explicit permissions are not presented as a sublicense to redistribute their artwork.
